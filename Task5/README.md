# План перехода на медицинскую платформу

Переход использует Parallel run: новая система сначала получает контролируемые
копии данных для сверки, затем становится единственным местом записи выбранного
процесса. Старый контур сохраняется для чтения и проверенного возврата.

## Применение

Cutover — окно перевода рабочих операций на новую систему. План является
проектным регламентом; даты, длительности и критерии уточняются по репетиции
и рабочему графику клиники. Первое окно касается профиля и записи на приём;
медицинская документация, лаборатория и платёжные адаптеры вводятся следующими
волнами по тому же порядку контроля.
