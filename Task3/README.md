# Стратегия защиты данных «Медикаменте»

Стратегия определяет, какие сведения защищаются, где требуется шифрование
хранения и каналов, как управляются ключи и как обнаруживаются нарушения.
Она распространяется на медицинскую платформу, существующие 1С, файловый архив,
рабочие места, аналитические наборы и резервные копии.

## Применение

Начальная точка — инвентаризация фактических носителей и сетевых каналов.
Средства защиты являются предложением для внедрения; выбор продукта не заменяет
настройку, проверку совместимости и модель угроз. Решения согласованы с
[целевой архитектурой](../Task2/architecture.md).
